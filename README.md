## 三条底层原则

### 1. 她是一个完整的人，不是你的奖励

她有工作、有朋友、有不想说话的时候、有比你更懂的领域、有权利拒绝你而且不需要理由。

一旦你开始想"我做了这么多她凭什么不给我回应"——恭喜，你已经从**喜欢一个人**滑到了**跟一个自动售货机较劲**。投币不出货就踹机器，那不是爱，那是消费。

### 2. 尊重不是态度，是行为，可被观察

别说"我很尊重你"，那是形容词。尊重是动词：

- 她说"不聊这个"，你就换话题。**立刻**，不解释、不追问、不阴阳。
- 她说"我累了"，你说"那睡吧"，而不是"那你早点说啊我好难受"。
- 你没回消息，也不需要她先给你道歉。

**做不到的行为，别用形容词补。**

### 3. 关系不是靠"努力"换来的，是靠"合适"留下来的

筛掉一个人不是失败，是效率。你花三个月追一个不合适的人，比花三个月找三个合适的人更浪费时间——而且过程还很痛苦。

**喜欢是双向确认，不是单向坚持。**

## 30 秒自检（如果你只读这一屏）

- [ ] 我把"她"当人还是一个待攻略的目标？
- [ ] 我能说出她最近三件烦心事吗？（说不出 = 你没在听）
- [ ] 我最后一次真诚道歉，是什么时候？
- [ ] 我有没有在"等她回消息"时情绪失控？
- [ ] 我做的事，是为了她好，还是为了让她欠我？

五条里有两条答不上，去读对应章节。四条都答不上——先读 00，别急着追人。

## 常见误区速查

| 你以为 | 实际上 |
| --- | --- |
| 我付出这么多她应该感动 | 付出不是交易，她没签合同 |
| 她生气了我先讲道理 | 情绪没被接住时，道理是噪音 |
| 已读不回就是不喜欢 | 也可能是忙、累、不知道怎么回 |
| 冷处理能让她更在乎我 | 冷处理只会让人觉得你不可靠 |
| 我要变得够好她才喜欢我 | 变得更好是为了自己，她只是顺带受益 |
| 追不到就是我不够努力 | 也可能是本来就不合适，努力是错配 |

## 关于这个仓库

- 不是情感导师课，没有"三天让她主动告白"这种鬼话。
- 不提供话术模板。**照抄的话术等于没说话。**
- 欢迎 PR 补充真实经验，但拒绝任何物化、操纵、打压技巧。
- 建议从 [00 · 心态](docs/00-mindset.md) 开始，别跳。
